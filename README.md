# **GUI From Scratch**

> **`NOTE:` This project is entirely for my learning purpose.**

Inspired by [RAD DEBUGGER](https://github.com/EpicGames/raddebugger) , [FILE PILOT](https://filepilot.tech/) & the [Handmade Hero Series](https://guide.handmadehero.org/), this is my attempt to build a GUI application (For Windows Currently) from scratch using Win32 API & other native APIs that the OS provides, that feels fast and snappy to use.

## Requirments
- MSVC compiler (Developer Command Prompt For VS)
Basically, you need [MSVC Build Tools](https://visualstudio.microsoft.com/downloads/?q=build+tools). 

- OS: Windows

## How to compile & run it?
- Run `uiBuild.bat` to compile the program. 
- Run `uiBuildNRun.bat` to compile & run the program. 

The output of the compiler will be in the `build` folder
